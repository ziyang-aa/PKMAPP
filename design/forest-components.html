开源组件灵感实验室（Uiverse · Motion Primitives · Origin UI · Vaul）

高人气微交互 · 可直接点击体验并复用到安卓
A · 弹簧滑动底块分段器（Sliding Pill Tabs） Motion Primitives / Origin UI

复用亮点：选中底块不是生硬闪烁，而是带弹簧阻尼跟随手指滑动到目标项；Android 原生可在 ForestSurface 中用 150ms ValueAnimator 平滑插值选中框左右边界。

B · 钢笔一笔画出对勾 + 待办完成横线 Uiverse.io (SVG Dash-Draw)

复用亮点：勾选瞬间方框微弹（1.06x），对勾像墨水钢笔一样从左到右一笔画出；用于「今日安排」待办时还可附带温柔的手绘横线划掉动画。

C · 森林叶片旋转胶囊开关（Morphing Leaf Switch） Uiverse.io (Scene Toggle)

复用亮点：把生硬的圆点开关变成带森林小叶片印记的圆钮，拨动时圆钮一面滑动一面 360° 轻巧旋转，轨道渐变为深松绿。
