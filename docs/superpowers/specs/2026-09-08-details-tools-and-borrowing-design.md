# 明细选择器与森林小工具设计

## 目标

将明细页的日期切换、账本切换和两个森林小工具从占位/系统风格入口，升级为可用的暖纸张森林绘本体验；汇率工具联网取得最新可用汇率，借钱统计支持“我借出”和“我借入”，并与记账页的对应分类联动。

## 范围

- 明细页：自定义纸张风月份选择底部弹窗、自定义纸张风账本选择底部弹窗。
- 汇率换算：独立页面，支持 CNY、USD、EUR、JPY、HKD，输入金额、原币种和目标币种后联网换算。
- 借钱统计：独立页面，按“我借出 / 我借入”查看日期、人物、金额和备注，并显示汇总。
- 记账联动：支出“借出”和收入“借入”记录保存后询问是否加入借钱统计；选择去填写时带入金额和日期。
- 本地保存：借钱记录使用 SharedPreferences 保存，并绑定当前账本。

## 非目标

- 本阶段不引入 Room、Compose 或 Kotlin。
- 汇率按公开参考汇率使用，不作为实时交易报价；网络失败时展示最近一次缓存结果。
- 不制作新角色或背景素材，不覆盖用户素材库中的任何文件。

## 交互设计

### 明细选择器

点击月份按钮打开低高度纸张底部弹窗，年份和月份分别使用可滚动的自定义单选列表，不使用系统 NumberPicker。弹窗底部提供取消和“查看这个月”，确定后同时刷新余额和交易列表；“本月”继续恢复系统当前年月。

点击账本按钮打开纸张底部弹窗。每个账本显示木牌风小图标、名称和当前选中状态；点击行立即切换并刷新明细，底部提供“新建账本”，输入为空时在输入框附近提示错误。

### 汇率换算

汇率页面保留明细页的返回门、固定森林背景和底部导航不选中状态。主体为一张纸张面板：金额输入、原币种选择、交换按钮、目标币种选择、结果金额、换算比例、同步日期和刷新按钮。首次打开自动刷新；刷新期间显示“正在寻找最新汇率”，失败时保留缓存并显示“网络不可用，使用上次同步”。

网络数据使用 `https://api.frankfurter.dev/v2/rate/{base}/{quote}` 获取单一货币对，客户端完成乘法换算和两位小数格式化。该 API 无需 API key，接口返回参考汇率和日期；客户端设置连接/读取超时并将最近成功结果缓存到 SharedPreferences。

### 借钱统计

借钱页面使用两个纸张胶囊切换：我借出、我借入。每个方向显示总金额、记录笔数和按日期分组的列表；列表项突出金额，下面显示人物和备注，日期单独作为分组标题。页面提供“新增一笔”入口，表单包含方向、金额、发生日期、人物和备注。

发生日期、金额、人物是必填项，备注选填；提交前在对应输入框显示中文错误。保存后立即刷新统计页并提示成功。

### 记账联动

支出分类保留“借出”；收入分类新增“借入”。保存这两类记录后，先完成原有交易保存，再弹出“加入借钱统计？”纸张对话框：去填写、暂不统计。去填写进入借钱页面，预填当前交易方向、金额和发生日期，人物留空要求用户填写；暂不统计不影响原交易。

## 数据结构

`BorrowingRecord` 包含：

- `id`
- `ledgerId`
- `direction`（`LEND` 或 `BORROW`）
- `amountInCents`
- `occurredAtMillis`
- `person`
- `note`
- `sourceTransactionId`（可为空）

`BorrowingRecordStore` 负责按当前账本读取、添加和持久化记录。JSON 存储在 SharedPreferences 中；读取坏数据时忽略坏条目，不让页面崩溃。

`ExchangeRateService` 负责线程池网络请求、JSON 解析、超时和回调；`ExchangeRateSnapshot` 只承载 base、quote、rate、date。Fragment 不直接解析网络响应。

## 视觉与可访问性约束

- 继续使用暖纸张、草木绿、木棕和橙色，不使用深色玻璃拟态。
- 所有可点击控件保持至少 48dp；图标使用现有 SVG/PNG 资源并给独立控件提供 contentDescription。
- 选择状态不能只依赖颜色，同时显示文字或选中标记。
- 网络加载、失败、缓存、空列表和必填错误均有可见文案。
- 汇率和借钱页面不扩展底部导航栏，返回操作回到明细页。

## 验收标准

- 点击明细月份和账本入口不再出现系统 NumberPicker/普通单选对话框；选择后明细数据正确刷新。
- 汇率页能在联网时显示请求日期、比例和结果；断网时不崩溃并保留缓存提示。
- 借出/借入记录可新增、持久化、按方向和日期显示；人物和日期为空时不能保存。
- 从记账页保存借出/借入后能看到联动询问，并能带入金额和日期打开借钱表单。
- JVM 单测覆盖日期选择、借钱必填校验、分组统计、持久化序列化和汇率解析/换算；Debug APK 可构建并在模拟器完成主要页面视觉检查。
