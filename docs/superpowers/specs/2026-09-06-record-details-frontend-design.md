# 记账与明细联动：第二阶段前端设计说明

## 1. 目标与边界

本阶段将当前的“记账”和“明细”页面壳替换为可实际演示的前端主流程：在本次应用运行内，用户可录入一笔收入或支出，并马上在明细页、当月汇总和账本列表中看到结果。

数据仍仅保存在内存，关闭应用即可重置。本阶段不接入 Room、文件存储、真实汇率接口、通讯录权限或云同步；借钱统计和汇率工具仅保留为可点击的入口卡片，留给后续独立阶段。

## 2. 架构与数据边界

新增 `data` 包，包含不可变的 `Transaction`、`Ledger` 和 `TransactionType` 模型，以及进程级单例 `InMemoryLedgerRepository`。Repository 提供当前账本、演示交易、创建账本、切换账本、添加交易和读取按日期排序交易的明确方法。

Repository 不依赖 Android `Context`、View 或 Fragment，因此金额汇总、分类统计和排序可用 JVM 单元测试覆盖。页面通过 `LedgerDataListener` 订阅内存数据变化：订阅者在 `onResume` 注册、在 `onPause` 注销；Repository 写入成功后通知所有当前订阅者。这样从记账页保存返回明细页后可立即刷新，同时避免把临时状态散落到控件中。

默认提供“生活账本”和包含餐饮、交通、工资等分类的演示数据。账本创建只要求非空名称；同名账本允许存在，因为个人账本可能按月份或用途重复命名，切换用唯一 ID 识别。

## 3. 记账页

页面顶部使用“支出 / 收入”单选切换。金额输入为必填项，接受大于 0、最多两位小数的人民币金额；金额格式错误时直接在输入框显示中文错误提示。

下方以可换行的分类芯片展示默认类别：支出为餐饮、网购、日用、交通、娱乐、住房；收入为工资、奖金、兼职、红包、理财、其他。用户先选分类才可保存；“自定义”打开一个简短文本输入对话框，确认后将该分类选中用于本次交易。

日期默认今天，通过日期选择器修改；备注可选。金额区旁提供四则运算计算器入口，计算器可进行加、减、乘、除、清空和退格，除以零时保留当前表达式并显示中文错误。点击“使用结果”将计算结果回填到金额输入框。

“保存这笔记录”先验证金额和分类，再将交易写入 Repository，显示简短成功反馈，并切换到明细页。日期、类型、分类、备注和金额均应被保留在交易对象中。

## 4. 明细页

页面从上至下为：当前账本名称与切换入口、便利小工具横向卡片、本月结余纸张卡片、按日期分组的交易列表。

便利卡片包含“汇率换算”和“借钱统计”，以统一 Vector Drawable 图标、标题和一句状态文案呈现。此阶段点击会说明功能正在准备，不伪造正式数据或网络状态。

结余卡显示当前账本本月收入、支出和结余；收入使用森林绿、支出使用 `expense_red`，不能仅靠颜色区分，文字标签也必须可见。交易条目显示分类、备注（为空时显示分类名）、日期、金额以及收入/支出文字。交易按交易日期倒序并按“今天 / 昨天 / M月d日”分组；没有交易时显示现有宝可梦空状态插画与“去记一笔”按钮。

账本切换以单选对话框实现；“新建账本”会先输入名称，创建成功后立即切换为该账本。此阶段没有账本删除，避免误删演示数据且不超出主链范围。

## 5. 视觉、交互与可访问性

所有页面继续使用既有森林绘本颜色、`PaperCard` 资源和 4/8dp 间距节奏。功能操作图标只使用同一风格的 Vector Drawable，插画只作装饰或空状态。

可点击图标和芯片的可点区域不得小于 48dp；有可见文本的装饰性角色图不重复播报；无文本图标按钮提供 `contentDescription`。使用原生 `MaterialButton`、`TextInputLayout`、`RecyclerView` 与选择对话框，维持按压反馈、语义和焦点顺序。所有滚动内容要预留底部导航栏空间。

## 6. 错误处理与测试

Repository 必须拒绝空账本名称、空分类、非正金额和空交易日期，并以明确异常或返回结果向调用方说明；Fragment 将这些错误转换为字段级中文提示。计算器的非法表达式、除以零和无结果回填均不能崩溃。

JVM 单元测试覆盖金额解析、计算器运算、账本切换、交易排序和月度收入/支出/结余汇总。Android 测试至少验证默认明细空状态/演示列表所需资源可加载，以及关键保存控件、金额输入和分类控件存在。构建通过后仍需在安卓模拟器或真机上检查小屏、横屏、深色系统模式下的布局与底部导航遮挡。

## 7. 不在本阶段实现

- 编辑、删除交易和借款记录详情。
- 汇率计算、借款统计的数据录入与联网更新。
- 图表、攒钱、我的页面的数据展示和资产汇总。
- Room、本地持久化、导入导出、头像选择、主题切换和云同步。
