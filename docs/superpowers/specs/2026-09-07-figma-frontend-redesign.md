# PKMAPP Figma 前端重设计说明

## 目标

将 PKMAPP 的前端从传统表单式界面调整为轻盈、温暖的森林绘本风移动账本；Figma 文件是可评审的视觉源，Android Java/XML 继续是最终实现目标。

## 视觉语言

- 画布：390 × 844 的 Android 手机画板，遵守状态栏与底部手势区域。
- 背景：米白纸张 `#F5F1E7`，而非纯白。
- 主色：森林绿 `#4E8146`；叶绿 `#A8D58C`；木棕 `#7B5C3B`；暖橙 `#D48A4A`。
- 语义色：支出 `#C75B4B`，收入 `#4E8146`，主要文字 `#3B352C`。
- 圆角与层级：卡片使用 20dp 圆角、浅木色描边和极轻阴影；不使用玻璃拟态或深色金融面板。
- 字体：中文使用系统无衬线字；数字以中等字重凸显。角色、场景和小物件是装饰，不承担信息表达。
- 图标：统一使用线性矢量图标；专属记账类别使用用户提供的透明 WebP 绘本按钮。

## 页面与关键状态

1. 主页面：固定底部五导航（明细、图表、记账、攒钱、我的），上方为可左右拖动的长幅卧室/森林场景；先留出三只角色背景插槽。
2. 明细：返回主页面入口、账本与月份选择、月度结余、汇率与借贷工具、按日期分组的交易记录。
3. 图表：收入/支出切换、周/月/年范围切换、折线趋势与排行榜；收入和支出不混在同一张趋势图。
4. 记账：默认支出，先选择圆形类别按钮；选定后显示金额、备注与日期滚轮，最终用主要按钮保存。类别为支出 18 项、收入 4 项。
5. 攒钱：多个目标卡片、进度条、创建与删除入口。
6. 我的：资产总览、头像和昵称入口、个人设置列表。

## 组件边界

- `App/Colors`：命名颜色变量，供所有页面使用。
- `App/Spacing`：4/8dp 节奏以及圆角、阴影、触控尺寸规则。
- `Navigation/Bottom`：五个文字导航项，当前项使用叶绿胶囊高亮；实际操作热区至少 48dp。
- `Header/Return`：功能页左侧为用户绘制的门型返回插画，右侧为页面标题；视觉图片可大于点击热区。
- `Record/CategoryTile`：透明 WebP 图标置于 64dp 圆形卡片中，文字独立位于下方，选中状态用叶绿描边与浅色底表达。
- `Record/EntryPanel`：类别确认后逐步显露金额、备注、日期和完成按钮，避免首屏同时出现完整计算器。

## 交互与可访问性

- 每个图标操作有文字或无障碍标签；装饰插画不传递业务状态。
- 底部导航和所有独立点击目标至少 48dp；点击仅改变透明度/高程，不造成布局跳动。
- 页面内容为可滚动区域并留出底部导航的安全间距。
- 默认亮色主题先完成；暗色主题、数据持久化、网络同步不属于本轮 Figma/前端视觉重构。

## 验收标准

- Figma 中存在设计令牌和六张 390 × 844 的移动页面画板，其中主页面、明细、图表、记账为第一批核心画板。
- 记账页能清晰呈现支出/收入切换、类别选择前后的渐进录入流程，以及用户的类别插画资源。
- Android 后续实现能直接映射到 Java Fragment 和 XML 布局，且不需要依赖网络字体或非本地图片。
