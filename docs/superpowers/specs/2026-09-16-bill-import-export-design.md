# 账单导入导出设计

## 目标

为芽叶记增加可迁移的账单备份能力，解决重装 APK 后本地数据丢失的问题：用户可以从“我的”页面导出当前财务数据，重装后选择备份文件，并在导入时选择完全覆盖或合并导入。

## 已确认的用户规则

- 导出使用一个备份文件，而不是多个 CSV 文件。
- 导入时提供“完全覆盖”和“合并导入”两个选项。
- 合并导入时，重复消费按以下三个字段判断：发生时间相同、金额相同、备注相同。
- 分类不参与消费去重。
- 导入后账单明细、图表和攒钱页面必须显示恢复后的数据。

## 备份文件格式

使用带版本号的 JSON 文件，扩展名为 `.pkmbackup.json`，示例文件名为 `芽叶记备份_2026-09-16.pkmbackup.json`。

备份文件包含：

- 文件格式版本和导出时间；
- 所有账本及当前账本编号；
- 所有交易记录；
- 所有攒钱目标、目标金额、已存金额和创建时间；
- 每个账本的初始资产和负债；
- 所有借入/借出记录。

头像、昵称和签到日期不属于账单备份范围。

格式版本用于以后增加字段时保持旧备份可识别。导入必须先解析并校验完整文件，确认成功后才允许修改本地数据。

## 导出流程

1. 用户进入“我的”页面并点击“导出账单”。
2. App 使用 Android 系统文件保存选择器创建 `.pkmbackup.json` 文件。
3. App 从账本仓库、攒钱存储、资产存储和借钱存储读取快照。
4. App 生成备份 JSON 并写入用户选择的位置。
5. 成功或失败通过页面提示反馈给用户。

导出不清除、不改变当前数据。

## 导入流程

1. 用户点击“导入账单”，通过 Android 系统文件选择器选择备份文件。
2. App 读取文件并校验格式版本、必需字段、金额、日期、账本关系和记录结构。
3. 校验失败时提示“备份文件无效”，保持本地所有数据不变。
4. 校验成功后显示导入方式选择：完全覆盖或合并导入。
5. 执行导入并显示结果统计。

### 完全覆盖

将备份中的账本、交易、攒钱目标、资产/负债和借钱记录替换本地对应数据，并恢复备份中的当前账本。覆盖操作在内存快照校验完成后一次性提交，不能先清空再尝试解析。

### 合并导入

- 账本优先按编号匹配；编号不存在时按完全相同的账本名称匹配；仍没有匹配项才新增账本。
- 交易保留本地已有记录。
- 导入交易使用“发生时间 + 金额 + 备注”作为重复键，分类不参与判断；匹配到已有记录或同一批导入文件中前面已加入的记录时跳过。
- 攒钱目标按目标编号匹配；已有目标保留本地状态，新目标加入。不会因为重复导入而重复增加已存金额。
- 资产/负债和借钱记录按其稳定编号匹配，重复项不重复加入；新记录加入。
- 完成后报告新增、跳过和覆盖的数量。

导入时间使用备份中保存的完整 `occurredAtMillis`，不重新生成日期，确保同一备份重复导入时判断稳定。

## 页面与自动同步

在 `ProfileFragment` 对应的“我的”页面增加两个操作入口：

- 导出账单
- 导入账单

使用 Android Storage Access Framework 的 `CreateDocument` 和 `OpenDocument`，不申请广泛存储权限。

导入完成后：

- 账本仓库替换或合并数据并通知监听器；
- 明细页重新读取当前账本交易；
- 图表页重新从交易计算周/月/年统计；
- 攒钱页重新读取目标存储；
- 当前“我的”页面刷新资产摘要并显示导入结果。

## 错误处理与安全边界

- 不接受空文件、非法 JSON、未知格式版本、缺字段、非法金额或非法日期。
- 读取或写入文件失败时只提示错误，不清理现有数据。
- 覆盖导入前完成所有校验，避免半导入状态。
- 合并导入遇到单条损坏记录时，整体备份导入失败并保留本地数据，避免用户得到不完整且难以察觉的结果。
- 不上传数据到服务器；备份文件由用户自行保存和传输。

## 测试范围

增加单元测试覆盖：

- 备份 JSON 的完整编码和解码；
- 非法版本、缺字段和非法记录被拒绝；
- 完全覆盖后账本、交易、攒钱目标和借钱数据一致；
- 合并导入按时间、金额、备注跳过重复消费；
- 同一批导入文件内的重复消费不会重复加入；
- 合并导入不会重复增加攒钱目标已存金额；
- 导入后仓库监听器收到数据变更通知。

增加 Android 测试覆盖：

- “我的”页面显示导入和导出入口；
- 点击入口能够启动系统文件选择流程；
- 导入成功后页面显示结果提示。

## 不在本次范围内

- 云同步、账号登录和服务器备份；
- CSV、Excel 或其他通用账单格式；
- 头像、昵称、签到记录迁移；
- 自动把普通消费推断为某个攒钱目标的存入记录。
