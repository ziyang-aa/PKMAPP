# 宝可梦森林绘本记账 App：前端设计说明

## 1. 本阶段目标

先完成一个可运行、可交互、便于继续修改的 Android 前端原型。使用 Java、XML
布局和 ViewBinding。页面使用临时内存数据，能够新增、编辑、删除和切换展示，但
关闭应用后允许重置。本阶段不接入 Room、本地持久化或真实网络接口。

最终确认前端后，再实现本地数据库、头像文件保存、汇率缓存和自动更新等数据层。

## 2. 技术与结构

- 单一 `MainActivity` 作为页面容器，不为首页单独增加 Activity。
- 首页和五个功能页面分别使用 Fragment，统一由底部导航栏切换。
- 启用 ViewBinding，避免手写视图查找代码。
- 使用 Java 11、AndroidX AppCompat 和 Material Components。
- 使用轻量的内存 Repository 管理临时账单、交易、储蓄目标、借款记录与个人资料。
- UI 状态和数据模型分离，后续可以把内存 Repository 替换为 Room，而不用重写页面。
- 功能图标统一使用 Material Symbols Rounded 风格的 Vector Drawable；插画使用 WebP。

## 3. 导航与首页

应用启动后首先显示 `HomeFragment`。首页主体是一张连续的横向长幅室内场景，像在
自己的森林卧室中。画面位于固定底部导航栏上方，用户左右拖动时移动同一张长图，
不是轮播图，也不自动切换图片。正式长图尚未提供时，先使用森林绘本占位背景搭建
同样的横向滑动行为，后续只替换图片资源。

底部导航栏固定显示五个入口：明细、图表、记账、攒钱、我的。点击入口进入对应
Fragment；在功能页按系统返回键回到首页。五个功能页之间可直接通过底部导航切换。

## 4. 视觉系统

整体采用 C 方案“森林绘本风”：奶油色再生纸背景、水彩草木、柔和圆角纸张卡片、
深绿色主色和少量暖橙色强调。三只主角为妙蛙种子、木守宫和草苗龟。

基础颜色：

- 页面背景：`#F5F1E7`
- 卡片纸色：`#FFF8DF`
- 森林绿：`#4E8146`
- 嫩叶绿：`#A8D58C`
- 木质棕：`#7B5C3B`
- 暖橙：`#D48A4A`
- 支出红：`#C75B4B`
- 正文墨色：`#3B352C`

卡片、按钮和输入框保持统一圆角与间距；功能性控件不使用 AI 生成图标。插画只用于
首页、空状态、成功反馈和局部装饰，不干扰金额、标题和操作按钮的可读性。

## 5. 明细页

页面顶部提供账单名称与切换入口，可创建新账单并切换当前账单。

内容顺序：

1. 便利小工具卡片：横向排列汇率换算与借钱统计等入口。
2. 本月结余卡片：同时展示收入、支出和结余。
3. 按日期分组的交易列表：动态展示收入与支出，支持空状态插画。

汇率工具的前端阶段使用模拟汇率和计算交互，并展示“更新时间”与“离线缓存”状态。
正式数据阶段再加入联网自动更新及本地缓存。

借钱统计分为“我借入”和“我借出”，记录姓名、手机号、其他联系方式、金额、日期、
备注和归还状态。支持新增、编辑、删除、标记已还，以及借入/借出金额汇总。

## 6. 图表页

顶部第一层切换“支出 / 收入”，第二层切换“周 / 月 / 年”。两类数据不在同一张图上
混合展示：

- 选择支出时，展示支出折线图和支出分类排行榜。
- 选择收入时，展示收入折线图和收入分类排行榜。

折线图前端先使用自定义 View 绘制，包含坐标、折线、节点、金额提示和空数据状态。
排行榜展示分类图标、名称、金额、占比和进度条。

## 7. 记账页

顶部切换支出与收入。用户可以输入金额、使用页面内计算器完成加减乘除，选择日期、
分类和备注。默认支出分类包括餐饮、网购、日用、交通等；收入提供工资、奖金、兼职、
红包等示例。支出和收入均支持新建自定义分类。

保存后写入临时 Repository，明细和图表立即刷新，并展示森林绘本风成功反馈。

## 8. 攒钱页

展示储蓄目标列表，例如北京旅游经费、恋爱经费。每个目标包括名称、目标金额、当前
金额、进度、可选截止日期和备注。支持创建、编辑、删除目标，以及增加或减少已存金额。

空列表使用草苗龟与储蓄罐插画；进度变化使用幼苗、金币和草苗龟角色素材进行轻量反馈。

## 9. 我的页

展示头像、昵称、总资产、现金/银行卡等资产摘要，以及主题设置入口。前端阶段头像选择
和昵称编辑只在内存中生效，资产数据由临时交易汇总。保留“风格切换”入口，但第一版
只提供森林绘本主题，后续再加入多主题资源映射。

## 10. 临时数据流

`InMemoryLedgerRepository` 作为单例保存本次运行期间的数据。页面只通过明确的方法读取
和修改数据，并在修改后通知相关页面刷新。应用提供一组演示数据，使所有列表、图表、
借款统计和储蓄进度在首次启动时即可查看与操作。

业务模型至少包括：账单、交易、分类、借款记录、储蓄目标、个人资料与资产账户。

## 11. 状态与错误处理

- 表单必填项缺失、金额无效或除以零时，在对应输入位置显示中文提示。
- 删除账单、交易、借款记录或储蓄目标前显示确认对话框。
- 没有数据时展示对应插画与明确的下一步按钮。
- 模拟汇率不可用时显示上次更新时间并允许继续使用缓存值。
- 横向首页图片缺失时显示主题色占位场景，应用仍可进入五个功能页。

## 12. 素材使用

已转换素材位于 `artwork/processed/android_ready/`。开发时将实际使用到的文件复制到
`app/src/main/res/drawable-nodpi/`，避免直接依赖素材工作目录。透明人物和装饰使用无损
WebP；不透明背景使用有损 WebP。所有 Android 资源名保持英文小写和下划线格式。

## 13. 验收标准

- 项目能够构建并在 Android 模拟器或真机启动。
- 启动页为可左右平移的单张连续长幅场景，底部导航固定。
- 五个功能入口与返回首页行为正确。
- 所有表单、切换、创建、编辑、删除、计算器和筛选交互可使用临时数据演示。
- 明细、图表与资产摘要会随临时记账数据同步刷新。
- 支出/收入图表严格分开展示，并支持周、月、年切换。
- 透明 WebP 不出现棋盘格或矩形底色。
- 主要页面在常见手机尺寸下没有文字遮挡、溢出或无法点击的控件。
- 单元测试覆盖金额计算、汇总、图表分组和储蓄进度等纯逻辑；关键导航与表单提供
  基础界面测试。

## 14. 暂不包含

- Room 数据库和正式数据迁移。
- 真实汇率网络接口、定时更新与离线缓存实现。
- 登录、云同步、多设备同步和应用商店上架配置。
- 第二套主题及完整主题切换实现。
- 尚未提供的正式首页横向长幅背景制作。
